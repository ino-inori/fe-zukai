書き方意味

      
○整数型: f(整数型: n)手続・関数の宣言。「整数型の値を返す関数 f。引数は整数 n」

      
整数型: x ← 0変数の宣言と初期化。← は代入（右の値を左の変数に入れる）

      
if (条件) … elseif (条件) … else … endif条件分岐。上から順に調べ、最初に当てはまったところだけ実行

      
while (条件) … endwhile条件が成り立つ間、繰り返す（最初に条件を判定）

      
do … while (条件)先に1回実行してから、条件を判定して繰り返す

      
for (i を 1 から n まで 1 ずつ増やす)i を 1, 2, …, n と変えながら繰り返す

      
data[i]、dataの要素数配列の i 番目の要素。要素番号は 1 から始まる（特に断りがない限り）

トレースのコツ

  

    
① 変数を列に並べた表を書く

    
頭の中だけで追うと必ずどこかで間違えます。上のトレース表のように、変数ごとに列を作り、値が変わるたびに1行書くのが確実です。

    
② ループは「1回目・2回目・最後の1回」に注目

    
ループの最初と最後（境界）で間違えやすい。「i が n のときに中に入るか？」「終わった時点での値は？」を丁寧に確認しましょう。

    
③ 配列の要素番号は 1 から

    
プログラミング言語（C や Python）は 0 から数えますが、試験の擬似言語は1 からです。data[1] が先頭。

    
④ 再帰は「呼び出しを積み重ねて、戻りながら計算」

    
自分自身を呼ぶ関数（再帰）は、上の「階乗」で呼び出しの積み重なりを確認しましょう。いちばん奥まで呼んでから、戻るときに掛け算されていきます。

    
⑤ 選択肢から逆算するのもアリ

    
「空欄に入る式」を問う問題は、選択肢を1つずつ当てはめて、小さな具体例（要素数3くらい）でトレースすると速く確実に解けます。
